## Decision

**NO-GO for public store submission at this time.**

All code-quality, accessibility, and test gates pass. The blocking items (GAP-001 through GAP-009) are operational and infrastructure gaps — not code defects. The application is **production-safe** for local builds and internal distribution. The GO criteria for public store release require:

1. Operator populates CI secrets (`CM_KEYSTORE_*`, `GOOGLE_MAPS_API_KEY`)
2. Apple Developer account setup, iOS signing configured
3. Backend wires `POST /api/auth/logout`
4. Store listings, screenshots, and legal links created
5. Physical-device testing matrix completed
6. iOS Privacy Manifest created
7. Release build obfuscation enabled with Crashlytics symbol upload

When items 1–7 are complete, re-run `flutter test`, `flutter analyze`, perform physical-device smoke test, and re-issue certification with **GO**.
